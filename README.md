# 🧠 精力助手 · 大脑效率革命

一个启发自《大脑效率革命》(Hyper-efficient) 的零依赖精力管理小工具：把大脑「三挡位」模型 + 精力节律做成一页可交互的仪表盘，帮你**明确当下该做什么、以哪个挡位去做、何时该充电**。

- **零依赖**：纯 HTML/CSS/JS + 一个极简 Node 本地服务，无需安装任何框架
- **内容源无关**：不绑定 Obsidian，只认一份统一的 `inbox/tasks.json`
- **AI 真拆解**：用脑量/难度由 Claude 读懂内容后判断，不靠关键词瞎猜
- **本地运行**：服务只绑定 127.0.0.1，数据仅存本机，不上传任何服务器

---

## 快速开始

1. **双击 `启动.bat`**（需已装 [Node.js](https://nodejs.org)），浏览器会自动打开 `http://localhost:8642`
2. 首次打开弹出「早晨流程」：填**今天几点起床** + **昨晚睡了多久**
3. 工具自动生成当天时间轴（精力地形图 + 当下安排）
4. 用终端 Claude 拆解你的 md（见下），任务自动导入并排进时间轴
5. 随时点「此刻」卡片下的 **🛠 检测我的档位** 或 **🆘 我卡住了** 获得即时建议

> ⚠️ **只双击 `启动.bat`，不要双击 `server.js`**。`server.js` 在本机关联的是 Windows 脚本宿主（WScript.exe），双击它会弹出「如何打开这个文件」的选择框——那不是启动入口。启动入口只有一个：`启动.bat`。

> 为什么要有本地服务？因为自动读取 `inbox/tasks.json` 需要 localhost（`file://` 下浏览器禁止 fetch）。直接双击 `index.html` 仍能手动导入 JSON，但体验不全。

## 三大核心概念

| 挡位 | 状态 | 建议动作 |
|------|------|----------|
| **挡位1 · 慢速/充电** | 脑子空转、累、困 | 散步 / 20 分钟小睡 / 喝水远眺 / 无脑小事 |
| **挡位2 · 心流/深度** | 能专注 | 关通知 / 单任务 / 写下「下一步动作」/ 25 分钟专注块 |
| **挡位3 · 冲刺/快速** | 亢奋 / 赶时间 / 紧急 | 设时限 / 列最小可交付 / 先完成后完美 / 事后充电 |

**用脑量轴**：每个任务标「低/中/高」用脑量 → 高用脑量排精力高峰（挡位2）、中排中等时段、低排午后低谷。任务类型的用脑量映射是**透明固定**的：深度=高、创意=中、常规=低、冲刺=高（不猜，你一眼能看懂）。

**创意错峰**：`创意/发散` 类任务（头脑风暴、创意写作、构思）和「深度专注」是两种需求——发散思维在精力低唤醒的**清晨/深夜**更旺，因此创意任务会被排到清晨或深夜边缘，而不是午前峰值。

## 任务怎么进来（AI 真拆解）

任务不是从标题猜难度，而是由 Claude **读懂 md 正文**后拆解。统一入口是一个 skill：

```
/decompose-tasks 你的文件.md
```

（可给多个文件或文件夹；支持 SQL、数学等任何科目，难度藏在正文也能看懂。）

skill 会：

1. 把 md 拆成「一句话、可执行」的有序任务
2. 对每条任务真判断 `type`（深度/创意/常规/冲刺）、`load`（低/中/高用脑量）、`estMin`（估时）、`priority`（优先级）
3. 按「先基础后进阶、先概念后练习、先前置后结果」排序
4. 写入 `inbox/tasks.json`

拆完回到工具，点任务面板的 **「重新读取 inbox」**（或直接刷新页面），任务即入列并排进时间轴。重复导入会自动去重，手动添加的任务始终保留。

> 拆解方法（含难度基准、SQL 示例）见 `.claude/skills/decompose-tasks/SKILL.md`。

**手动添加**：任务面板底部输入框 + 类型下拉（深度/创意/常规/冲刺），可再选优先级、用脑量、预计分钟，回车即入列。

## 每日 8 点自动开启（Windows）

用「任务计划程序」，把执行程序指向 `启动.bat`（会自动起服务并开浏览器）：

```
schtasks /create /tn "BrainGears" /tr "\"C:\Users\everglow\my-project\brain-gears\启动.bat\"" /sc daily /st 08:00
```

## 数据与备份

- 所有数据存在浏览器 `localStorage`（设置 / 任务 / 检测历史 / 睡眠日志 / 当日安排）
- 「设置」面板可**导出 JSON 备份**、**清空当日**安排与检测历史
- `inbox/tasks.json` 是 AI 任务的输入契约，格式见 `tasks.schema.json`

## 说明与边界

- 精力节律为**简化启发式模型**，仅供自我管理参考，**非医学建议**
- 工作/学习占比默认 75%，可在「设置」里调整（50%–90%）
- 本地服务仅绑定 127.0.0.1，不对外网开放
- 日后可套 Electron 壳升级为「托盘常驻 + 开机自启 + 系统通知」的常驻助手（界面代码 100% 复用）
